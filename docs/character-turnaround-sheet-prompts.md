# 角色三视图提示词怎么写（附模板与 6 个范例）

角色三视图提示词先写这张板给后续镜头复用什么，再写换衣服也不变的辨识特征、唯一一套当前造型，以及正面、侧面、背面各靠哪个特征认人。光线按要比较的内容选，背景只求不干扰识别，并写明画面内无视图标签、箭头和图注。

## 角色三视图提示词模板（可复制）

身份和造型由创作者在视觉设定里先定好；视图、光线、背景和排除项按这张板的用途来挑，项目或创作者另定了版式时从项目。身份还没定，就先列出候选请创作者拍板，别用文案糊过去。

| 字段 | 写什么 | 依据 |
|---|---|---|
| 用途 | 下游要靠这张板保持什么：认人、认这套衣服、认某个状态或某个部位 | 下游镜头的复用需要 |
| 身份锚点 | 少量换装后仍成立、看得见、彼此不重复的特征，如轮廓、比例、一个局部标记、一组颜色或材质关系 | 视觉设定（已确认） |
| 当前造型 | 从头到脚只写一套，先写剪裁、层次、领口袖口、材质和主次色，再写气质 | 视觉设定（已确认） |
| 视图 | 为用途挑最少够用的视图；多个视图必须是同一时刻、同一造型 | 按用途选，项目有固定版式时从项目 |
| 侧背锚点 | 侧面和背面各由哪个锚点承担识别 | 从已确认锚点里挑，逐个视图核对 |
| 光线 | 让要比较的结构看得清的光 | 按要比较的内容选 |
| 背景 | 不抢识别的纯色或简洁背景 | 按用途选，创作者可改 |
| 保持与排除 | 这张板最容易多出来或漂走的东西 | 这张板的漂移风险 |

### 可复制的三视图提示词骨架

1. 【项目风格标签】人物设定参考图，用于后续镜头认出〔角色名〕和〔这套造型／这个状态／某个部位〕。
2. 身份锚点：〔换衣服也不变的可见特征：脸型、发际、体型、永久痕迹、长期配饰〕。
3. 当前造型：〔从头到脚只写一套：发型整理方式、上衣、下装、鞋、配饰及其佩戴位置〕。
4. 视图：同一时刻、同一造型的〔正面／左或右侧面／背面〕全身视图并排，等高，自然站立，表情〔平静／低强度〕；侧面选锚点所在的那一侧。
5. 侧面与背面：〔哪几个锚点在侧面、背面也要看得见，例如扎起头发后露出的后颈标记、肩背轮廓〕。
6. 光线：〔五官位置用均匀正面光；骨骼体积用侧光；布料纹理用大面积柔光；剪影用轮廓光〕。
7. 背景：〔不干扰识别的纯色或简洁背景〕。
8. 版面：画面内无视图标签、无引线箭头、无尺寸标注、无图注。
9. 保持与排除：〔这张板最可能多出来的东西，如第二套衣服、手持道具、新伤、模板审美句〕；不出现可读文字。

填完删掉空项、括号和“身份锚点：”“视图：”这类字段名，读起来像一段能直接交给画师的工作说明。多角色时每个角色单独写一条，只有对比板才把几个人放进同一张；角色名与视觉设定里的登记名一致。风格标签按项目统一前置，例如【真人风格，写实风格】或【国漫风，二次元画风】，设计描述本身不带风格词。

## 6 个角色三视图提示词范例

六个范例用同一部江边轮渡题材的[漫剧](https://zenstory.ai/zh/glossary/manju)：售票员苗秋禾二十出头，船老大宋满仓六十岁出头，两人的身份和造型已在视觉设定里确认。

### 范例 1：全身三视图（身份板）

> 【国漫风，二次元画风】人物设定参考图，用于后续镜头认出苗秋禾和她的售票造型。二十出头的女性，圆脸，下巴短，眉距略宽，左耳垂一颗小黑痣，肩窄，上背微圆。齐肩黑直发在脑后扎低马尾，露出后颈右侧一块指甲盖大小的浅褐胎记；藏青立领短外套拉链拉到胸口，内搭浅灰圆领针织衫，右小臂套一只橙色布袖套，深灰直筒裤，黑色平底帆布鞋。同一时刻、同一造型的正面、左侧面、背面全身视图并排，三者等高，自然站立，双手垂在身侧，表情平静。均匀柔和的正面光。浅米色纯色背景。画面内无视图标签、无引线箭头、无尺寸标注、无图注。不加首饰，不拿票夹或任何道具，不出现可读文字。

全身三视图靠体态和轮廓认人：背面看上背弧度、马尾和后颈胎记，侧面看上背弧度和马尾；耳垂痣留给范例 2。袖套写明“右小臂”，三个视图就不会各戴各的。

### 范例 2：头肩面部识别板

> 【国漫风，二次元画风】苗秋禾头肩面部识别参考图：圆脸，下巴短，眉距略宽，左耳垂一颗小黑痣，齐肩黑直发扎低马尾，发际线完整露出。正面头肩与左侧面头肩两个视图（露出左耳垂）并排等高，表情平静。均匀的正面平光，浅米色背景。画面内无视图标签、无引线箭头、无图注。只画到领口，不表现服装全貌。

平光让五官位置好比较，代价是脸部体积变平；服装交给范例 1。

### 范例 3：服装造型板（正面加背面）

> 【国漫风，二次元画风】宋满仓船上工作装参考图，用于核对衣服层次和挂件位置。六十岁出头的男性，个子矮，腿短，腰身粗，肩膀宽厚，方下巴，花白寸头。他穿褪色的深蓝帆布马甲，敞着怀，里面是洗白的军绿长袖衫，袖口卷到小臂中段，腰后右侧别一条旧白毛巾，黑色胶鞋，裤脚塞进鞋口。正面与背面全身视图并排等高，头身比例按他本人的矮壮体型，双臂自然下垂。大面积柔光，看清帆布磨白的纹理和毛巾的垂挂位置。浅灰背景。画面内无视图标签、无引线箭头、无图注。马甲上没有文字或标志。

毛巾别在腰后，正面看不到，所以补背面；层次靠正背两面已够核对，侧面省掉。

### 范例 4：状态板（同一造型加包扎）

> 【国漫风，二次元画风】苗秋禾状态参考图，沿用她的售票造型：圆脸、耳垂痣、低马尾、右小臂袖套和整套衣服保持不变，只在右手掌缠一圈白纱布，结打在虎口一侧，四根手指露出。正面全身一个视图，右手自然抬到腰前，让包扎可见，表情平静。均匀柔光，浅米色背景。不加血迹或其他伤口，不换衣服，不出现可读文字。

起因和有效范围（第 6 集缆绳擦伤，到第 8 集为止）记在条目信息里，正文只写变化和保持项。

### 范例 5：不合模板身材的角色（全身三视图）

> 【国漫风，二次元画风】人物设定参考图，用于后续镜头认出宋满仓本人。六十岁出头的男性，个子矮，腿短，腰身粗，肩膀宽厚，方下巴，花白寸头，右手小指缺了末节。他穿船上工作装：深蓝帆布马甲敞穿，军绿长袖衫卷袖，腰后右侧别一条旧白毛巾，黑色胶鞋。同一时刻、同一造型的正面、右侧面、背面全身视图并排等高，头身比例按他本人的矮壮体型，不拉长腿部，双臂自然下垂。高位斜侧光，让方下巴、肩背厚度和腰腹体积在侧面清楚可比较。浅灰背景。画面内无视图标签、无引线箭头、无尺寸标注、无图注。

矮壮是他的识别点，写进视图句，免得模板里的“修长”把他拉高；侧光让体积可比较。

### 范例 6：剪影对比板（漫剧远景用）

> 【国漫风，二次元画风】剪影对比参考图，用于远景和逆光镜头分清苗秋禾与宋满仓。两人并排，宋满仓比苗秋禾矮约半个头，各一个右侧面全身视图：苗秋禾窄肩，上背微圆，脑后低马尾在轮廓上形成一个小凸起；宋满仓矮而宽，肩背厚，寸头轮廓平，腰后毛巾在轮廓外垂出一角。深色纯色背景，轮廓光勾出外形与发型剪影。画面内无标签、无箭头、无图注。

轮廓光会把脸压进暗部，所以这张只做剪影对比，认脸仍靠范例 1 和 2。

## 三视图提示词为什么先写用途

用途决定后面每个字段：近景认脸做面部识别板，全身调度里认衣服做全身板并补上必要的背面，跨镜头复用的状态单独做状态板。背景和视图数量不属于角色身份，按用途挑。

人物板要让后面的镜头认出同一个人此刻的这一套状态。一张身份板只保一个身份、一套自洽的造型，几套造型、几种情绪不挤进同一张；要比较两个角色，另做对比板（见范例 6）；一次抬手、一个眼神属于镜头，交给分镜和[视频提示词](https://zenstory.ai/zh/drama-skills/seedance-prompts)。

## 三视图侧面和背面靠什么认人

正面看得到整张脸，侧面只剩侧脸，背面看不到脸。逐个视图问一遍：观众凭什么认出她？

- 正面：脸型、五官的相对位置、正面可见的配饰。
- 侧面：面部侧轮廓、上背弧度和站姿重心、发型剪影；痣或胎记只在它所在的那一侧看得见，要写明画左侧面还是右侧面。
- 背面：发际形状和发型剪影、肩背线的宽窄与重心、后颈的永久痕迹。

锚点必须在那个视图里真的看得见。眉距、瞳色、唇形这类只在正脸看得清的特征撑不起侧面和背面；为当前用途检查侧面与背面是否确实有可辨认依据，不把“每面至少一个”当成统一硬指标。全身视图靠体态和轮廓认人，面部小标记留给近景和头肩板。

视图之间常见的毛病是变脸、换衣服、配饰挪位置，比如右臂的袖套到背面跑到左臂；把佩戴位置和相对大小写进三个视图共用的造型句。跨镜头的连续性见 [AI 短剧角色一致性](https://zenstory.ai/zh/drama-skills/character-consistency)。

漫剧如果主要靠剪影认人，锚点不换，只换画法：发际形状落到发型剪影的缺口上，体态落到肩背重心上。找不到可靠画法时交回创作者，别换一个更好画的身份。

## 三视图提示词要不要写“正面”“侧面”标签？

标签不要画进板里。这张板之后要当参考图用，板上的字会带进后面的镜头，提示词里再加“不要文字”也清不掉，要先裁切、清理、遮罩或换参考图。多视图并排时直接写“画面内无视图标签、无引线箭头、无尺寸标注、无图注”，再写清几个视图、怎样并排、是否等高。

## 三视图用什么光：按要比较的东西选

每种光让一类结构看得清，同时压掉另一类，所以先问这张板要比较什么。

| 要比较什么 | 选什么光 | 代价 |
|---|---|---|
| 五官相对位置、妆面、服色和图案 | 均匀正面光 | 颧骨、鼻梁、下颌的体积变平 |
| 骨骼体积和轮廓起伏 | 侧光或高位斜侧光 | 暗侧细节丢失，左右不对称被放大 |
| 布料纹理、肤质 | 大面积柔光 | 轮廓边界变软 |
| 磨损、金属反光、工艺痕迹 | 小面积硬光 | 过渡丢失，瑕疵被放大 |
| 发型剪影、服装廓形 | 轮廓光或逆光边缘光 | 面部信息被压掉，不能单独当身份板 |

顶光让眼窝、鼻下、颌下的纵向结构可比较，代价是暗区里的识别细节和服装层次会丢；底光颠倒日常明暗，做识别板时不用。状态板可以用场景里的实际光源，光向要和已确认的场景一致。

光型只按要比较的内容挑，“女角色一律柔光、男角色一律侧光”这类按性别、年龄、贫富或题材套用的默认，先删掉。强戏剧阴影遮住脸或服装结构的图，不能当识别板。

## 三视图提示词里的九头身等模板词为什么会改掉角色

人物板模板如果给每个角色都挂上同一串审美句，比如“九头身、修长双腿、完美五官”，遇到和已确认身份冲突的角色，身份优先，模板让位。宋满仓矮壮腿短，挂上“九头身”就成了另一个人；又因为这句话出现在每张板上，下游会把它当作画风统一。本来就修长的角色，也要由自己的锚点写出修长。

排查办法：把一批角色的提示词摆在一起，找出逐字重复、又和身份无关的句子。能追溯到某个角色当前视觉设定的留下，追溯不到的删掉，或改写成这个角色真实的锚点。

“网红脸、顶级美女、8K、杰作”同理，挤掉锚点又给不出可核对的事实。审美词要么落到构图、材质或光向这类看得见的选择上，要么删掉。

## 三视图提示词常见错误与改法

- 一张板里出现两套衣服、两种发长或干湿并存：只绑一套造型，其他造型拆成独立条目。
- 手持道具和当下表情写进了身份：道具需要反复识别时才单独建板，表情交给分镜；识别板常用平静表情，但表演测试可以按用途给出表情范围，不把不同剧情时刻混成一张姿态。
- 表单字段直接贴进正文，比如“角色：船老大／年龄：60”：改写成自然描述。
- 生成结果漂移后原样重发同一段描述：先判断是身份、构图、文字还是状态出了问题，再改对应的那一句。

发出前用这张清单过一遍：

- [ ] 第一句写了用途和角色名
- [ ] 身份锚点换衣服后仍然成立
- [ ] 整张板只有一套造型
- [ ] 每个视图都有看得见的锚点
- [ ] 光线对应要比较的内容
- [ ] 写了画面内无标签、箭头、尺寸标注和图注
- [ ] 没有与身份冲突的模板审美句

## 用 Drama Skills 怎么做

装好本仓库的 skill 后（对应 [short-drama-image-prompts](../skills/short-drama-image-prompts/SKILL.md)）：在 Claude Code 里说：“用 /short-drama-image-prompts 为 EP001 已确定的人物写三视图提示词”（Codex 里写作 `$short-drama-image-prompts`）。它把带 `IMG-...` 编号的可复制正文存进 `剧集/<EP>/图片提示词.md`，本身不生成图片；出图要转 `short-drama-produce`，确认具体任务后才执行。

## 常见问题

**三视图一定要白底吗？**

不用。Drama Skills 把白底三视图当作一种项目选择；浅灰、浅米等纯色或带环境的背景都可以，只要不干扰识别，也不把一次性的场景光和陈设写进身份。

**三视图提示词用中文还是英文写？**

跟随项目设定。Drama Skills 的可复制正文按项目配置 `short-drama.json` 里的提示词语言输出；没有这份配置时默认英文，同一任务里保持一种语言。

**角色受伤或换衣服要重做三视图吗？**

身份三视图不用重做。换装或伤势会跨镜头出现、影响识别时，先在视觉设定里登记成新的造型版本或状态版本，再写造型板（新衣服）或状态板（只写变化和保持项）；只在一个镜头里出现的，写进那一镜的分镜。
